fframes Studio · desktop app

The library renders it. Studio runs the loop.

fframes turns Rust into video. Studio is the desktop app around it, so you can direct that video with a coding agent.

Install the Windows preview How it works

01 · Setup

It brings its own toolchain

A managed SDK pins Rust, fframes, FFmpeg and Skia. Opening a project never installs anything or runs Cargo.

02 · Select

Point at it, then ask

Click an object, a scene or a range. The agent gets the frame, the object and the Rust code that drew it.

Note  Objects need ids in the code. The Studio template adds them; imported crates still get scenes, ranges and rectangles.

03 · Agent

Your agent, on a copy

Studio starts the Claude Code, Codex or ACP agent you already use. It edits a draft copy, never your project, and every permission it asks for is your call.

04 · Check

Nothing counts until it renders

Every edit is built, rendered and inspected before it replaces what you are watching. A failure gets one repair turn; then the old video stays.

05 · Timing

Cut without compiling

Split, trim and move clips. Timing lives in timeline.json, so the preview changes and the build does not.

06 · Project

It’s still just Rust

A Studio project is an ordinary crate. Close the app and cargo run renders the same video.

my-video/
  src/lib.rs          the video
  src/main.rs         the normal fframes CLI
  media/  style/      assets and tokens
  timeline.json       cuts and trims
  studio.json         SDK pin
  AGENTS.md           guidance for any agent

07 · Try it

Install, then open an example

Windows preview

Per user, no administrator rights.

PS> irm https://github.com/khanhthanhdev/fframes-desktop/releases/latest/download/install.ps1 | iex

From a checkout

Then install the SDK on the Setup screen.

$ cargo run --locked --manifest-path desktop/Cargo.toml -p fframes-studio

Status  Windows is the tested platform and the preview is unsigned. Linux runs the tests in CI. macOS is not fully tested yet.

Processes, the five checks, click to code, and the fence around the agent.
