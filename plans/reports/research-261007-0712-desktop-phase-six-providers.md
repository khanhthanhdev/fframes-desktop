## Executable qualification recommendations

1. Qualify Claude and Codex first as **candidates**, then select the two best actual pass results. Keep Pi and Antigravity experimental until the same workflow passes. Do not predeclare the winners or implement a native driver before a specific measured ACP gap is recorded.
2. Record provider/adapter/runtime versions, executable and script/dependency hashes, full launch arguments, auth variable **names**, OS/architecture, protocol/client-capability snapshot, model and account entitlement class. Pin published stable packages and resolved dependency bytes; never use `latest` or preview channels as reproducible evidence. Launch through Studio's absolute app-local path rules; package-manager PATH resolution during research is not a product launch design.
3. In disposable retained working copies, perform authenticated create → edit Rust → build/inspect → preview → Apply/Undo → export. Exercise streamed completion, follow-up questions, permission approve/decline and failures. Capture redacted outcomes and evidence hashes, never credentials or personal prompts. Test every advertised model/mode control against the host's actual protocol version; do not adopt draft AIR extensions silently.
4. Send a bounded PNG containing a randomly chosen visible property unavailable in text; require the correct property in the result. Exercise every one of the nine Studio tools through `studio-mcp` and, separately where needed, `studio-tools`. Verify real broker results, revision/task scope, image retrieval and denied stale/expired capabilities. Pi's current MCP limitation must be visible; stored MCP parameters are not tool access.
5. Stop during streaming, a permission wait, local shell work and a long/background command; also crash the adapter. Measure descendants and post-stop file writes, reap the complete owned writer tree and verify no escaped writer before capture/Apply or provider handoff. A `cancelled` prompt result is insufficient. Include repeated cycles and project/app close.
6. Persist provider identity, native session id, exact launch identity and stable working-copy identity; restart the adapter and Studio, then call negotiated load and continue an authenticated edit. Verify replay boundaries/no duplicate transcript, tools and refreshed task capabilities. Missing/expired/unusable restoration must start a new session with an explicit continuity notice and current project context. Native memory does not move between providers.
7. Demonstrate Claude → Codex (or equivalent passing pair) handoff with old writer reaped before new launch; transfer current revision, task summary, selection/style and diagnostics, then verify retained project and new edits. Repeat for unsaved drafts, cancelled/failed turns and stale selection. Qualify each advertised OS independently; upstream platform archives cannot bypass Studio's existing publication/process gates.

Unresolved questions: Antigravity ACP image/tool/cancel semantics; authenticated restart behavior for all four; real writer ownership on each platform; Pi model and CLI tool access; exact published dependency closures and any runtime prerequisites. These require live qualification, not further claims from initialize.
