## Reproduction and boundaries

Build the official pinned FFmpeg install, assemble the SDK and package the executable using [the native procedure](../../docs/desktop/phase-zero-feasibility.md). Run `qualify-linux-native.py` against the packaged executable/SDK with a fresh output directory and `--isolated-user`. It types and clicks using a first-painted geometry signal, validates counters/input/snippet, saves logs/screenshot/environment and returns nonzero on failure. The Linux CI job runs this procedure; Windows/macOS matrix builds and the remote workflow have not been executed here.

To reproduce the manual lifecycle rows, start the packaged spike with the verified SDK and loopback-only account environment. Connect Real Worker, Step Worker Frame, Crash Worker, then type into the native field while the prior image remains visible. Verify the owned worker PID exited. Restart, Step again, and verify the generation increases. Change source after painting and click the title: selection must reject the stale revision. Restart/build the changed title, Step and reselect its updated snippet, then Close and verify no owned worker remains. Recorded screenshots and process identities are retained with the ledger evidence.

Linux managed compilation, worker isolation and source selection have scoped native evidence. The composite GPUI gate stays unmet for physical-display GPU pixel/alpha/readback/resources and real IME. Windows/macOS native checks and authenticated ACP edit/cancel are NOT_RUN; the latter is explicitly deferred by user choice.
