# fframes Studio proposal

The current proposal is an agent-driven GPUI desktop app with a Rust backend, ACP connections, video preview/timeline, style presets, and selection-based source editing.

It supersedes the earlier template-first proposal after clarification of the intended product. Rust video source remains the project authority; templates provide starting points.

Read the [overview](desktop/README.md), [research findings](desktop/research.md), [technical architecture](desktop/architecture.md), and [implementation plan](desktop/implementation-plan.md).

The documents cover inspected Zeron/Cap implementations, current official ACP references, compilation and rendering boundaries, preset design, source retrieval, provider qualification, and multiplatform installation. They are planning artifacts; an app or installer has not been implemented in this change.
