The workspace

Watch it, select it, change it.

The preview plays the build of your project. Click a scene, an object or a time range, and the selection goes with your next request to the agent. Timing changes on the timeline apply without rebuilding Rust.

  • Click to select

    Pick an object, a scene or a time range in the preview. Object selection depends on the project.

  • Cut on the timeline

    Split, reorder and trim scenes. Edits write timeline.json, with undo and redo.

  • Checkpoints and history

    Every accepted change is a checkpoint on your computer, and the last agent edit can be undone.

  • Managed SDK

    Rust, FFmpeg and fframes come with the SDK. The Setup screen installs it step by step.

Your agent

Say what should change.

Your coding agent edits the Rust project in a draft working copy. The last working preview stays on screen while the next revision takes shape.

  • Claude Code and Codex through their own CLIs
  • Pi, Antigravity, OpenCode and any ACP agent
  • Sign-in stays with each agent; Studio never stores an API key

Checks

Every edit is built and checked first.

Studio builds the candidate, then checks rendered frames, boundary frames and audio before the edit reaches your project. A failed or cancelled build keeps the previous preview.

  • Apply automatically, or review the diff and choose Apply
  • Turn files off before you apply them
  • A permission policy decides what the agent may do alone

Timeline

Change the rhythm. Keep the source.

Split a scene, move the outro or trim a clip's edge. Timing edits write timeline.json and update the preview without rebuilding Rust.

  • Scene tracks and audio clips on one timeline
  • C splits, drag edges to trim, Shift-drag for a range

Export

Make the video. Take it with you.

Choose a format your project's worker supports, set the size and frame rate, and render a file. Follow the progress or cancel.

  • MP4 with MPEG-4, H.264 or HEVC, and WebM with VP9
  • Full or half size, the video's own frame rate or 30 fps

Use cases

What people make with it.

Anything you can draw with fframes: titles, charts, formulas, captions and scenes, written as code and changed by asking. The prompts below are examples.

  • Launch and release videos

    A title, three feature beats and a logo sting, kept in the same repository as the product.

    “Make a 20-second intro for our v2 launch.”

  • Lessons and explainers

    Formulas, plots and step-by-step figures for math, physics, chemistry and computer science with fframes-kit.

    “Animate a binary search over 16 numbers.”

  • Data stories

    Charts that grow from your own CSV or JSON. Change the data and render again; the same input gives the same frames.

    “Turn sales.csv into a bar race by month.”

  • Social clips and title cards

    Vertical and square formats from one project, with your fonts, colours and timing.

    “Make a vertical version with bigger text.”

  • Captions and lyric videos

    Subtitles and words timed to audio, with the audio mix on the same timeline.

    “Highlight each word as it is sung.”

  • Talks and slide decks

    Animated slides with presenter stops, played full screen with Present.

    “Add a slide that explains attention.”

Or install from a terminal

One command, no administrator rights.

macOS (Apple silicon) and Linux x64

$ curl -fsSL https://github.com/khanhthanhdev/fframes-desktop/releases/latest/download/install.sh | sh

Windows PowerShell

PS> irm https://github.com/khanhthanhdev/fframes-desktop/releases/latest/download/install.ps1 | iex

From a checkout: cargo run --locked --manifest-path desktop/Cargo.toml -p fframes-studio. Then install the SDK on the Setup screen.

Windows is the tested platform. The macOS and Linux builds are early previews, and no build is code-signed yet.

Questions

Frequently asked.

What is fframes Studio?

A native desktop app for making videos in code. You describe a video, watch it, select a scene or an object in the preview, and ask your coding agent to change it. The agent edits an ordinary fframes Rust project; Studio handles setup, compilation, preview, validation, history and export.

Is it free?

Yes. Studio and the fframes framework it builds on are open source under the MIT license. You bring your own coding agent.

Which coding agents can I connect?

Claude Code and OpenAI Codex connect through their own CLIs. Pi, Antigravity and any other agent that speaks the Agent Client Protocol, such as OpenCode, connect through ACP. Sign-in stays with each agent; Studio stores only the names of sign-in variables, never their values.

Do I need Rust or FFmpeg installed?

No. Rust, FFmpeg and fframes come with the managed SDK, which the Setup screen installs step by step. On Windows the only extra is Visual Studio Build Tools with C++ and clang, and the install script offers to set that up for you.

Which platforms are supported?

Windows x64 is the tested platform. macOS on Apple silicon and Linux x64 have early preview builds, installed with install.sh. No build is code-signed yet.

Who owns the project files?

You do. A project is a plain Rust crate in a folder you choose, and its source stays the authority for the video. Importing an existing fframes project keeps your files and Git history and adds only studio.json. Checkpoints and agent history stay on your computer.

Can the agent break my video?

Every agent edit is built and checked before it reaches your project: rendered frames, boundary frames and audio. Under manual review you read the diff and can turn files off before you apply it, and Undo last agent edit reverts an accepted change. A permission policy decides what the agent may do on its own, from asking every time to allowing edits inside the working copy.
